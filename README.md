# Узел

Справочник автомобильных поломок: марка → поколение → узел → симптом → решение.

Это MVP для Влада. Без регистрации, данные лежат в `src/data/catalog.ts` — карточки можно добавлять как обычный текст.

## Запуск

```bash
cd uzel
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Что уже есть

- Каталог Lada (Калина I, Гранта I) и Toyota Corolla E150
- Карточки с проверками, шагами, альтернативами и демо-комментариями
- Поиск по симптому и модели («стучит», «не заводится», «чек», «Калина»)
- Схематичные рисунки узлов, не чужие фото из мануалов

## Как добавить поломку

Откройте `src/data/catalog.ts` и добавьте объект в массив `guides`. При необходимости сначала допишите марку в `brands` и поколение в `generations`.
